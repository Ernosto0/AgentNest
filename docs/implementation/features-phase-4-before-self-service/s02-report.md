## Decisions (documented in the security docs)

- Odd ports refused: only the scheme default (80, 443). Business sites do not need others and internal admin services live there.
- IP literals refused outright instead of checked: a business has a hostname; this also removes every decimal/octal/hex parsing ambiguity between our parser and the OS resolver.
- Cross-host redirects are allowed at fetcher level (each hop fully re-checked) because `example.com` -> `www.example.com` is common; the importer then only follows same-site links.
- No decompression: `Accept-Encoding: identity`; a site that sends gzip anyway fails with `WEBSITE_NOT_HTML`. Chosen over bounded decompression for simplicity; revisit if real sites fail.
- No headless browser: script-rendered sites yield little text. Documented as excluded.
- Prefill is exposed by a tiny GET endpoint (not by extending the run status).
- `http://` page URLs are kept on candidates (the Session 01 code dropped everything but `https://`).
