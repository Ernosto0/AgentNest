## Adaptations, limits and open questions

- **Research:** Meta primary business-login/webhook pages returned HTTP 429 on 2026-10-23. V-01/V-02/V-03/V-05/V-08/V-09 and P7-00 are still open; older documentation claims were not freshly reconfirmed. All existing Meta fixtures are synthetic, never recordings. Vite/Cloudflare primary docs were accessible for configuration only.
- **Media/config:** Meta requires S3 in every environment. `MEDIA_PUBLIC_BASE_URL` is reserved and cannot expose local media. AWS uses the actual region; R2 defaults to `auto`; public HTTPS signing/fetch reachability remains V-09. Mixed mock/S3 publishing is unsupported. Token ring generation needs `generate-key --kind token-encryption`; default generation is `SECRET_KEY`.
- **OAuth/refresh:** absent actual returned grants means no capability. Short-exchange flat/wrapped envelopes remain provisional. Disconnect invalidation, unchanged reconnect identity/credentials, daily refresh ledger/attempt leases and `FOR NO KEY UPDATE` workspace mutex must remain intact. Live subscription/access/story behavior still needs research.
- **Deletion:** optional erasure is synchronous when safe, otherwise a durable job waits for send verification without consuming attempts. Queued/running/dead cleanup fences new Meta authorization. Tokens/payloads are cleared immediately; no unconditional erasure deadline/reconnection promise is made. Immutable ledger/audit history is preserved.
- **UI:** public `mock_requires_demo_workspace` is necessary because `demo_tools_enabled` does not describe connection policy. Simulation follows provider provenance, not the workspace flag. History caches are removed on optional erasure; affected views are invalidated. Holding a post requires later owner reapproval.
- **Harness:** no live probes, recorder, bucket requests, public tunnel, credentials collection, paid calls, deployment, App Review or push occurred. Harness skip/failure safety is covered offline, but real probe behavior remains unverified. No tests or claims substitute for owner/live acceptance.
- **Verification history:** the first full frontend run had 496 passes and one image-loading assertion race. The same expected blob-src assertion now waits for the loaded image in both affected existing tests; the failed log/JUnit are retained and a full rerun passes. Earlier focused authoring failures and static/type fixes are recorded in the Session 4 report. No failing full run is hidden by an isolated retry.
