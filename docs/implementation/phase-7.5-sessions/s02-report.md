## Implemented contract

- Migration `0019` (`20261026_0019_phase_7_5_agent_core_records.py`) follows head `0018`. It adds `account_agents`, `agent_delegations`, `agent_threads`, `agent_events`, `agent_sessions`, `agent_steps` and `agent_actions`, with workspace composite keys, account-scoped event/thread/operation links, uniqueness, state checks and indexes. Existing social accounts are backfilled `legacy`/`inactive`; a trigger initializes future accounts the same way. No delegation row is seeded.
- `agent_runs` accepts task `account_agent_step` and a nullable composite step FK. Existing reply/content subjects gain `origin` and nullable action links; old rows default to `legacy`. Agent-origin content links require the same account. Reply drafts lack an account column, so Session 07 must verify the conversation's account before linking an action. The polymorphic approval row likewise requires Session 03 subject/account validation. An action link is not authorization.
- `app/agent/repository.py` writes an ordered event and ID-only `agent_wake` job in one caller transaction, deduplicates source identity, builds intent keys from account/thread/goal/source/action/target/semantic slot rather than model wording, and returns the existing action for a repeated intent. Account-first short locks serialize duplicate source routing. `app/agent/transitions.py` supplies compare-and-swap state transitions with same-transaction audit rows. Session 05 owns orchestration and budgets.
- The `agent_wake` handler currently fails closed if an agent is active, pending Session 05's replacement. It cannot silently mark active work complete. Inactive/absent agent work is harmless. No account is activated by Session 02.
- [Data model](../../architecture/data-model.md#310-account-agent-core-phase-75-session-02-migration-0019) and [canonical contract](../../architecture/account-agent-contracts.md) record the implemented schema and boundaries. The migration refuses downgrade to `0018` if any agent evidence or changed configuration exists; a clean disabled backfill can downgrade.
