# Open Questions and Provisional Defaults

**Purpose:** Every decision that cannot be made responsibly with current information. For each one this file records its impact and a **reversible provisional default**, so that implementation is never blocked by a non-critical uncertainty.
**Rule:** When a question is answered, update this file (move it to "Resolved" with date and outcome), update the affected ADR, and reference the change in the phase doc that consumes it.

WhatsApp has per-message costs, business verification and policy risk ([platform-capabilities.md §2](platform-capabilities.md)).
